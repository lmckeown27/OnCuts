## 🔌 Testing the Mock Data

### Start the Backend
```bash
cd backend
npm run dev
```

### Test Endpoints

#### Get All Campuses
```bash
curl http://localhost:3001/api/dev/campuses
```

#### Get All Barbers
```bash
curl http://localhost:3001/api/dev/barbers
```

#### Health Check (Shows Mock DB Stats)
```bash
curl http://localhost:3001/api/dev/health
```

#### Reset Mock Data
```bash
curl -X POST http://localhost:3001/api/dev/reset
```

### Frontend Access

Visit `http://localhost:3000` and click:
- **Consumer** → See all 6 barbers in discovery feed
- **Barber** → See pending requests and analytics
- **Admin** → See moderation queue and platform stats
