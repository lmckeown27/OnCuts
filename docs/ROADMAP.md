# CampusCuts Product Roadmap

## Vision

Become the #1 peer-to-peer service marketplace for college campuses, starting with barber services.

---

## Phase 1: MVP Launch (Weeks 1-10) ✅

### Goals
- Launch at single pilot campus
- Onboard 10-20 barbers
- Process 100+ bookings
- Validate product-market fit

### Features
- [x] Student registration & authentication
- [x] Barber onboarding & profiles
- [x] Visual barber discovery
- [x] Booking system
- [x] Payment processing (Stripe)
- [x] Review system (blockchain-based)
- [x] Basic analytics dashboard
- [x] iOS app (SwiftUI)
- [x] Backend API (Node.js)
- [x] Smart contracts (Aptos)

### Success Metrics
- 100+ registered students
- 10+ active barbers
- 50+ completed bookings
- 4.5+ average rating
- <5% cancellation rate
